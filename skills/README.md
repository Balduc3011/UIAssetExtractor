# Skill cho Claude (Cowork)

`ui-asset-extractor-task/SKILL.md` giúp Claude trong app Cowork xử lý task của tool
(chế độ "Claude app (Cowork)") khi được nhắn **"Làm task UIAssetExtractor"**.

Cài vào tài khoản Claude của bạn: nén thư mục `ui-asset-extractor-task` thành file .zip,
rồi thêm vào mục **Skills** trong Settings của Claude. Mỗi tài khoản chỉ cần làm một lần.
